在你的网站嵌入日主小测

用一张虚构的八字盘，让读者练习找日主。小测可以用键盘作答，也无需填写出生信息。

单独打开小测 · 阅读日主指南

嵌入文章或课程

把下面的代码粘贴到支持 iframe 的页面。预留约 540 像素的高度，窄栏或大字号可以适当加高。

<iframe
  src="https://chilayt.github.io/bazi-midnight-case/exercise/zh-hans/"
  title="Bazi Diff 日主小测"
  loading="lazy"
  sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"
  style="width:100%;max-width:32rem;height:34rem;border:1px solid #b4c7bc">
</iframe>
